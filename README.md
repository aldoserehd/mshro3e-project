# Mshro3e App

A modern React Native app built with Expo SDK 51 for project management with beautiful UI and Arabic support.

## Features

- 🎨 Beautiful, modern UI with card-based design
- 🌍 Full Arabic language support with RTL layout
- 📱 Smooth animations and transitions
- 📊 Project tracking dashboard
- 🎯 Onboarding screens
- 🌈 Gradient designs and modern color scheme

## Tech Stack

- Expo SDK 51
- React Native 0.74.5
- React Navigation v6
- React Native Paper
- Lottie Animations
- i18n for internationalization

## Getting Started

1. Install dependencies:
```bash
npm install
# or
yarn install
```

2. Start the development server:
```bash
npm start
# or
yarn start
```

3. Run on your device:
- Press `i` for iOS simulator
- Press `a` for Android emulator
- Scan the QR code with Expo Go app

## Project Structure

```
src/
├── screens/         # App screens
├── components/      # Reusable components
├── navigation/      # Navigation configuration
├── styles/          # Global styles
├── utils/           # Utility functions
├── assets/          # Images, fonts, animations
├── constants/       # App constants (colors, etc.)
└── locales/         # i18n translations
```

## Available Scripts

- `npm start` - Start the Expo development server
- `npm run android` - Run on Android
- `npm run ios` - Run on iOS
- `npm run web` - Run on web browser
- `npm run lint` - Run ESLint
- `npm run format` - Format code with Prettier
